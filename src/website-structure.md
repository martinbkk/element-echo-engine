
# Fruten Fraten Website Structure

## Overview
A one-page, dark-themed crypto token website with playful, cartoonish styling and a dog mascot theme.

## Design Elements
- **Theme**: Dark background with vibrant neon accents
- **Colors**: Purple, blue, green on black
- **Style**: Playful, cartoonish, 3D elements
- **Interactions**: Smooth scrolling, hover effects
